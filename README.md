# Raz-Ebrat-mars

This is my portfolio project for the Code the Dream Intro to Programming course.

## About the Project

This portfolio introduces who I am, highlights my experience, skills, certifications, selected projects, and provides ways to connect with me.

The project was built using:

- HTML
- CSS
- JavaScript
- GitHub API

## Features

- Responsive portfolio layout
- Navigation links to different sections of the page
- Skills inserted dynamically with JavaScript
- Selected GitHub repositories displayed using the GitHub API
- Leave a Message form with JavaScript functionality
- Remove button for submitted messages
- Connect section with email, GitHub, and LinkedIn links

## Project Structure

- `index.html`
- `css/index.css`
- `js/index.js`
- `images/` (optional image assets)
- `README.md`

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code or another code editor.
3. Open `index.html` in your browser.

You can also use the Live Server extension in VS Code:

1. Open the folder in VS Code.
2. Right-click `index.html`.
3. Select **Open with Live Server**.

## Notes

The Projects section uses the GitHub API to retrieve selected repositories from my GitHub account.
